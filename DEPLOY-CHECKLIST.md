# Checklist di rilascio StayPilot

- [ ] Repository GitHub privato; nessuna chiave segreta nei file.
- [ ] Nuovo progetto Supabase creato.
- [ ] `supabase/schema.sql` eseguito senza errori.
- [ ] URL Site URL e Redirect URLs configurati in Supabase Auth.
- [ ] Vercel collegato al repository e deployment completato.
- [ ] URL e chiave pubblica Supabase configurati nella schermata iniziale.
- [ ] Registrazione e conferma email provate.
- [ ] Creazione/modifica/eliminazione struttura provate.
- [ ] Creazione/modifica/pubblicazione guida provate.
- [ ] Link pubblico provato in una finestra anonima.
- [ ] Isolamento dati Host A / Host B verificato.
- [ ] Nessun dato demo o segreto pubblicato.
- [ ] Backup, privacy policy, termini e contatti di supporto aggiunti prima di utenti reali.
- [ ] Pagamenti, fatturazione e limiti dei piani rimangono disabilitati finché non implementati e testati.
